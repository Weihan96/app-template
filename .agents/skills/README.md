# Repository Skills

This directory contains Codex project skills using the official repository layout.

- Put each skill in its own folder under `.agents/skills/`.
- Each skill should have a `SKILL.md` entrypoint with `name` and `description` frontmatter.
- Keep skills focused on one repeatable workflow.
- Commit these files to the repository when the workflow is team-specific.

Current skills:

- `find-icon`: choose and document reusable UI icons
- `first-run-setup`: bootstrap a fresh machine for this repository
- `shadcn-mcp`: use the shadcn MCP server to add and adapt registry components
- `telegram-integration`: standardize Telegram bot and webhook implementation work
- `wecom-integration`: standardize enterprise WeCom integration work
- `acceptance-criteria`: standardize how feature work records acceptance criteria and verification steps
- `create-prototype`: extract a project name and clone this repository into a renamed prototype
