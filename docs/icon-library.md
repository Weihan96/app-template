# Icon Library

Reusable icon choices paired with semantic intent.

| Context | Recommended icon | Why |
| --- | --- | --- |
| Launch, deploy, go live | `Rocket` | Signals momentum and release |
| AI workflow, automation | `Bot` | Clear automation metaphor |
| Database, schema, storage | `Database` or `DatabaseZap` | Data layer and performance |
| Knowledge, docs, resources | `BookCopy` | Reference material |
| Messaging, notifications | `Send` | Delivery and outbound actions |
| Security, validation | `ShieldCheck` | Trust and correctness |
| Dashboard, overview | `LayoutDashboard` | Product workspace |

Extend this file whenever a new icon decision becomes reusable.
